# Salon Queue Management System

**Live demo:** https://salon-queue-hetul.vercel.app
**Hosted on:** Vercel (Frontend) + Supabase / Render (Realtime Backend)
**Staff Demo PIN (Reception / Barber / Admin):** `1234`

## About
A real-time, mobile-first Salon Queue Management System built using a spec-driven Vibe Coding workflow. Customers can join the queue remotely from their phones, track live wait times in English or Gujarati, and receive instant turn alerts, while receptionists, barbers, and the waiting-area TV stay synchronized in real time.
